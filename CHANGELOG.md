# Changelog

## v1.0.0 — 2026-10-14

First public Glitchify release, based on the device-confirmed v9 build.

- Retains the working Eevee integration and standard Spotify interface.
- Adapts Chroma's player-state and track class lookups for the supplied Spotify binary.
- Uses native-player lyrics with the LRCLIB default migration.
- Disables conflicting Chroma interface changes and filters unavailable settings entries.
- Suppresses the in-app Metal performance overlay.
- Fixes foreground music haptics continuing after pause while retaining background haptics.
- Applies the Glitchify name and pastel glitch Spotify-symbol icon.

No new paid-feature unlocks or server-side capabilities are introduced. Functional confirmation applies to the configuration documented in the README.
